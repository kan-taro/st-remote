# ST-Remote (Bose SoundTouch Remote)

Bose SoundTouch シリーズを、デスクトップから最小限の操作でコントロールするための軽量リモコンアプリです。
公式アプリの重快さに疲れた方や、シンプルな操作を好む方向けに作成しました。

![ST-Remote Icon](https://github.com/あなたのユーザー名/st-remote/blob/main/build/icon.png?raw=true)
*(※アイコンのパスは実際のGitHubのURLに合わせて適宜修正してください)*

## 概要

本アプリは Bose が公開している **Local API** を使用し、ローカルネットワーク経由でスピーカーを直接操作します。Bose のクラウドサーバーを介さないため、高速に動作するのが特徴です。

### ⚠️ 重要な注意事項 (2026年5月問題)
Bose 公式による SoundTouch シリーズのサポートは **2026年5月** に終了することがアナウンスされています。
本アプリはローカル通信を利用しているため、サポート終了後も基本的な操作（音量・プリセット切り替え）は継続できると予想していますが、将来的な動作を完全に保証するものではありません。

## 主な機能

- **ボリューム操作**: 1クリックでの音量調整
- **プリセット切り替え**: プリセット1〜6の即時呼び出し
- **低音（Bass）コントロール**: 公式アプリでは深い階層にある低音調整に直接アクセス
- **マルチプラットフォーム**: Windows (.exe) および Mac (.dmg / Apple Silicon対応)

## インストール方法

本リポジトリの [Releases](https://github.com/あなたのユーザー名/st-remote/releases) ページから、お使いの環境に合わせたバイナリをダウンロードしてください。

- **Windows**: `ST-Remote-Portable-1.0.0.exe` (インストール不要で実行可能)
- **Mac**: `ST-Remote-1.0.0.dmg` (M1/M2/M3/M4チップに最適化済み)

※未署名のアプリのため、起動時にセキュリティ警告が出る場合があります。Macの場合は「右クリック ＞ 開く」で実行してください。

## 使い方

1. アプリを起動します。
2. お使いの Bose SoundTouch スピーカーの IP アドレスを入力し、「接続」を押します。
3. デスクトップの隅に置いて、作業中のお供にご利用ください。
